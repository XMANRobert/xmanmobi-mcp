# Xmanmobi review kit

Use this folder to prepare a reproducible reviewer walkthrough. Public files contain no credentials or customer data.

## Public submission

- MCP gateway source in `server/`.
- OAuth 2.1 + PKCE reference in `oauth-reference/`.
- Guarded write API reference in `backend-reference/`.
- Advertising methodology Skills in `skills/`.
- Recording script and test-report template in this folder.
- Simulated-data specification in `simulated-data-spec.json`.

## Private reviewer submission

Provide through the review form, never GitHub:

- Production MCP URL: `https://ai.xmanmobi.com/mcp`.
- Dedicated reviewer username and temporary password.
- The simulated customer name and expected visible account.
- A recording URL accessible without requesting permission.
- Completed test report with screenshots or redacted outputs.

Do not provide Google refresh tokens, Meta access tokens, OAuth signing secrets, database credentials, or real customer data.
