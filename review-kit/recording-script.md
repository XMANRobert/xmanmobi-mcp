# Continuous review recording script

Record one continuous video. Hide bookmarks, password managers, developer tools, tokens, and unrelated customer names.

1. Show `https://ai.xmanmobi.com/mcp` configured as `xmanmobi` in the client.
2. Start OAuth login, show the Xmanmobi sign-in page and read/write consent, then complete authorization with the dedicated reviewer account.
3. Ask Xmanmobi to list available customers and confirm only `Xmanmobi Review Demo` is visible.
4. Analyze the last 7 days of Google Ads, drill into Campaigns and keywords, and show the inefficient and efficient simulated Campaigns.
5. Run data-quality analysis and show the intentional stale/missing-data finding.
6. Ask for a 10% budget-change proposal. Show that the proposal does not alter the resource. Confirm in a separate prompt, execute it, then open the audit record.
7. Create a review Search Campaign, Ad Group, responsive search ad, keyword, and location/language targeting. Show each created object is `PAUSED`.
8. Open the BI automation page. Show account policy limits, global emergency stop, report-freshness guard, notifications, and run details. Keep the real automation policy disabled during review unless the reviewer explicitly requires execution.
9. Demonstrate refusal cases: another customer ID, budget change over 50%, creation without `confirm=true`, and an expired proposal.
10. End on the audit page and summarize the IDs created during the recording.
